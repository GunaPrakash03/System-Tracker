A screenshot interval is snapped to the tracker's slot interval, because a screenshot can only be attached to a time slot that exists. Asking for a shorter interval than the slot captures once per slot rather than producing screenshots the dashboard cannot show.

Stored in Gauzy against each employee, so there is no separate service to run. Apps are matched on process name — what the tracker reports, such as chrome, code or postgres. Matching is on the longest entry contained in the name, so terminal also classifies gnome-terminal-server, and an exact entry always beats a partial one. The same app can be productive for one department and unproductive for another.

Browsers work by exception. A browser's time is recorded per tab, so classify the browser itself — chrome: Productive, firefox: Productive — and then list only the tabs that differ, matching on words from the page title: youtube: Neutral, spotify: Unproductive. Every other tab takes the browser's category. You do not need an entry per site.

An application matching nothing at all is left unclassified and counts towards no category — it appears in its own group on the App categories tab, so gaps in this list stay visible rather than quietly inflating Neutral.
